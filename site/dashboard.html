💻 Agent-ready CLI examples

Save the copied credential to an owner-only file. These commands reference the file and never put the bearer value in page content, shell history, or process arguments.

Set the authority and token file

export OCTOSTORE_URL=https://api.octostore.io
export OCTOSTORE_TOKEN_FILE=/path/to/octostore-token

Hold one exact item

AGENT_WORKER=./run-agent
octostore-supervisor lock "repo/octostore/issue-1842" - "$AGENT_WORKER" -- \
  octostore lock hold "repo/octostore/issue-1842" \
    --ttl 120 --acquire-timeout 60 --json

Check current status

octostore lock status "repo/octostore/issue-1842" --json

Watch for ownership changes

octostore lock watch "repo/octostore/issue-1842" --json
